# 运动健康助手 App · 可运行成品

一款"懂科学、有温度、能闭环"的私人健康管家移动端原型，依据 `设计计划.md` 实现。

## 运行方式

**方式一（最简单）**：直接双击 `index.html`，用浏览器（建议 Chrome/Safari）打开即可。  
**方式二（推荐，体验最佳）**：在本目录启动本地服务，再用手机或浏览器访问：

```bash
# Python 3
python -m http.server 8080
# 然后浏览器打开 http://localhost:8080
```

> 用手机浏览器访问同一局域网地址（如 `http://<电脑IP>:8080`），即为真实移动端体验。

## 技术说明

- 纯原生 **HTML + CSS + JavaScript**，零构建、零第三方依赖、可离线运行。
- 图表全部为**自绘 SVG**（进度环 / 折线 / 堆叠条 / 热力图）。
- 算法（恢复评分、个性化计划生成、跑步训练营、虚拟宠物能量）均为**真实 JS 计算**，非静态图。
- 数据以内置 mock 模拟，并通过 `localStorage` 思路在会话内沉淀（运动→恢复→趋势→宠物 数据互通）。

## 功能地图（对应任务四大模块）

| 底部 Tab | 覆盖需求 |
|---|---|
| 首页 | 今日核心建议、身体电量/恢复评分、关键数据、快捷开始 |
| 运动 | 多源运动类型选择、进行中 GPS/心率跟踪、个性化训练计划、跑步教练训练营（5K→全马） |
| 数据 | 健康仪表盘、恢复与训练准备度、趋势分析（周/月/年）、睡眠阶段分析 |
| 社区 | 动态（点赞/评论/话题）、线上挑战赛（个人/团队+排行榜）、虚拟宠物养成 |
| 我的 | 体能测评、成就墙、算法透明"为什么"、隐私合规（GDPR/个保法）、商业化预留 |

## 文件结构

```
运动健康助手APP/
├─ 设计计划.md          # 详细产品设计计划（定位/IA/算法/设计系统/里程碑）
├─ index.html           # 入口
├─ README.md            # 本文件
└─ assets/
   ├─ css/style.css     # 设计系统 + 组件样式
   └─ js/
      ├─ data.js        # 模拟数据 + 核心算法（恢复评分/计划/宠物…）
      ├─ charts.js      # 自绘 SVG 图表库
      └─ app.js         # 路由 + 状态 + 全部页面与交互
```

## 合规与无障碍

- 隐私：最小必要采集、明确同意、本地优先加密、数据导出/删除/撤回授权。
- 算法透明：每处建议提供"为什么给我这个建议"解释，采用相对个人基线的 z-score，避免新手被给过高强度。
- 无障碍：系统字体栈支持 Dynamic Type、对比度达标、≥44pt 点击区、语义化结构。
