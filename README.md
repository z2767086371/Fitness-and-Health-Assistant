# 运动健康助手 App · 可运行成品

一款"懂科学、有温度、能闭环"的私人健康管家移动端原型，依据 `设计计划.md` 实现。

## 运行方式

**方式一（最简单）**：直接双击 `index.html`，用浏览器（建议 Chrome/Safari）打开即可。  
**方式二（推荐，体验最佳）**：在本目录启动本地服务，再用手机或浏览器访问：

```bash
# Python 3
python -m http.server 8080
# 然后浏览器打开 http://localhost:8080
```

> 用手机浏览器访问同一局域网地址（如 `http://<电脑IP>:8080`），即为真实移动端体验。

首次打开会先进入 **登录/注册** 界面：注册一个账号（密码可点 👁 切换明文/密文）即可进入；登录态会被记住，刷新后无需重复登录；在「我的 → 退出登录」可返回登录界面。

## 技术说明

- 纯原生 **HTML + CSS + JavaScript**，零构建、零第三方依赖、可离线运行。
- 图表全部为**自绘 SVG**（进度环 / 折线 / 堆叠条 / 热力图）。
- 算法（恢复评分、个性化计划生成、跑步训练营、虚拟宠物能量/等级、用户等级经验）均为**真实 JS 计算**，非静态图。
- 状态栏左上角时间与系统时间实时同步（每秒刷新）。
- 数据本地持久化：个人档案、自录健康数据、运动/饮食/饮水记录、社区动态、虚拟宠物、登录账号均存于浏览器 `localStorage`（仅本机、不上传服务器）。

> ⚠️ 登录/注册为**纯前端演示**，账号密码明文保存在本机 `localStorage`，不具备真实安全性，请勿使用真实密码。

## 功能地图

| 模块 | 覆盖需求 |
|---|---|
| 登录/注册 | 账号 + 密码进入 APP；密码明文/密文（圆点）切换；登录态记忆；退出登录 |
| 首页 | 今日核心建议、身体电量/恢复评分、关键数据、快捷开始、连续打卡与等级经验卡 |
| 运动 | 运动类型选择、进行中 GPS/心率跟踪、个性化训练计划、跑步训练营（5K→全马）、运动记录（自动保存 + 手动录入） |
| 数据 | 健康仪表盘、恢复与训练准备度、趋势分析、睡眠阶段分析、**录入今日健康数据**、年度活跃热力图（基于运动记录） |
| 社区 | 动态（点赞/话题/**发布自己的动态**）、挑战赛（个人/团队 + 排行榜）、虚拟宠物养成（能量 + 等级） |
| 我的 | 编辑个人资料（含头像上传）、体能测评、等级与经验、成就墙、算法透明、隐私合规、退出登录、商业化预留 |

## 用户自录数据（替代演示数据）

默认展示内置演示（mock）数据；用户可在以下入口录入自己的真实数据**替代**演示数据（不录入则保留演示）：

- **健康指标**：数据页「录入今日健康数据」——心率/HRV/血氧/压力/体温/睡眠时长与评分/体重/体脂/肌肉，保存后自动重算恢复评分、同步睡眠分析图（留空字段保留演示值）。
- **运动记录**：结束运动自动保存，或运动页「运动记录 → ＋ 手动记录」。
- **饮食/饮水**：首页「记录饮食」弹层——选餐次、快速添加/自定义食物、清空记录、饮水计数。
- **个人资料**：我的页「编辑个人资料」——姓名/头像上传/性别/年龄/身高/体重/目标/水平/器械/个人基线（影响恢复评分）。
- **一键清空**：数据页「清空录入 · 恢复演示数据」。

## 等级与宠物（真实升级）

- **用户等级**：完成运动 +50、手动记录 +30、加入挑战 +30、录入健康 +20、发布动态 +10、记录饮食 +5、喝水 +1，经验累计自动升级（`exp_next` 递增）；首页等级卡、我的「等级与经验」页可查看进度与获取方式。
- **虚拟宠物**：运动/喂养充能，累计能量与经验并升级（`exp_next` 递增）；形态随能量变化（瞌睡/普通/活力/闪耀），状态持久化。

## 合规与无障碍

- 隐私：最小必要采集、明确同意、本地优先存储；设置内提供"数据权利"入口（导出/删除/撤回授权，演示预留）。
- 算法透明：每处建议提供"为什么给我这个建议"，采用相对个人基线的 z-score，避免新手被给过高强度。
- 无障碍：系统字体栈支持 Dynamic Type、对比度达标、≥44pt 点击区、语义化结构。
